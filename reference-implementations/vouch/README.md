# Vouch reference implementation

This directory preserves the imported Vouch product doctrine, legal/copy rules, routes, provider assumptions, validation instructions, and UI inventory as a reference-only example.

Nothing under this directory is an active reusable contract. Adopting a Vouch-specific rule requires an approved specification and, when architectural, an accepted ADR.

- `context/docs/`: product, architecture, launch, legal/copy, design, and UI reference documents.
- `context/instructions/`: Vouch-specific audit, implementation, and validation guidance.
- `.agents/contracts/`: historical machine-readable Vouch contracts.
